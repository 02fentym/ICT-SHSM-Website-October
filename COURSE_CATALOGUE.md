# Course catalogue source and rules

Source: [SHSM Handbook](https://docs.google.com/document/d/1dYxL7WV-ElbDch7KeeK4K5PVShxuKKXZQxBqjSBlsQc/edit), Bundle of Credits (Revised Sept 2026) and Co-op sections. Read 12 October 2026.

- 8 horizontal tiles represent 9 credits: 4 major, Mathematics, English, one Arts/Business/Science/Guidance choice, and one two-credit co-op tile.
- The catalogue contains the handbook's exact category assignments. Slash notation is expanded into individual course codes (for example ICS3C/U → ICS3C and ICS3U).
- Shared codes use their major/math course name as the canonical title where the handbook abbreviates or varies names in the complementary list.
- TDJ3M is not in the handbook's major list. Removed from Programmer and Robotics Engineer recommendations at the user's explicit request; their fourth slots remain open.
- DCO3O is a conditional major option. The student must plan a separate second co-op block and confirm it with the SHSM lead. Required DCO3OC co-op credits never fill major slots.
- Regular-semester co-op: 2 credits, DCO3OC, one semester, morning periods 1–2 or afternoon periods 3–4. Summer: six weeks, all day, availability/approval and strict attendance; course code must be confirmed with Ms. Meilach.
- Selection checks prevent the same course code from filling two major/complementary slots. The co-op tile represents one required two-credit experience.
- Plans are held only in page memory, individually for each identity. Selection does not represent enrollment, earned credits, or approval. Reloading resets plans.
