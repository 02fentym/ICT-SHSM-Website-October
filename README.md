# ICT SHSM Website October

Static ICT SHSM website for AY Jackson SS. Built with HTML, CSS, and JavaScript.

## Preview

Serve this folder with a local static web server, or open `index.html`.

## Deployment

GitHub Pages publishes the root of the `main` branch.

## Course explorer

Includes eight student identities and exploratory course selection. Course-source notes are in `COURSE_CATALOGUE.md`. Selections do not represent enrolment or earned credits.
